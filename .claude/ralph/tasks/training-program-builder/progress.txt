## Codebase Patterns

- JSON imports in TypeScript tests require casting: `const items = jsonData as MyType[]` since TypeScript infers string types from JSON, not literal union types
- Exercise images are stored in `/images/` directory with filenames like `00251201-Barbell-Bench-Press_Chest_thumbnail@3x.jpg`
- Types are exported from `/types/` directory (e.g., `types/exercise.ts`)
- Static data lives in `/data/` directory with tests in `/data/__tests__/`

- **Learnings for future iterations:**
  - `react-native-mmkv` v3 uses `createMMKV({ id })` (not `new MMKV()`), and `remove(key)` (not `delete(key)`)
  - MMKV instance is module-level in the storage file, so tests share state — call `clearAllMMKVInstances()` in `beforeEach`
  - Use `import 'react-native-mmkv'; declare module 'react-native-mmkv' { ... }` to augment existing package types without replacing them
